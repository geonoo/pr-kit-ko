# 커밋 메시지 규칙

형식:

```text
<type>(<scope>): <제목>

<본문 - 무엇을/왜>

<푸터 - 이슈 번호 등>
```

type 예시:
- `feat`: 새 기능
- `fix`: 버그 수정
- `docs`: 문서
- `refactor`: 동작 동일 리팩터
- `test`: 테스트
- `chore`: 빌드/도구

제목:
- 50자 안쪽, 명령형("~한다" 대신 "~함" 또는 영어 명령형)
- 끝에 마침표 없음

예시:

```text
feat(auth): OTP 재전송 대기 시간 표시

사용자가 재전송 버튼을 반복 누르지 않도록
초 단위 대기 상태를 화면에 보여 준다.

Refs: WM-34253
```
