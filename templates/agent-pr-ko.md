# 에이전트용: PR 본문 작성 프롬프트

아래 규칙으로 현재 브랜치 diff를 바탕으로 GitHub PR 본문을 한국어로 작성해 주세요.

## 규칙
- 제목: 50자 안쪽, 무엇을 바꿨는지 명확히
- 본문 섹션: 요약 / 변경 이유 / 변경 내용 / 테스트 / 리스크·롤백
- 추측하지 말고 diff에 있는 사실만 적기
- 시크릿·토큰·개인정보 언급 금지
- `Co-authored-by: Cursor` 등 생성형 도구 트레일러 넣지 않기
- 테스트 섹션에는 실제로 돌린 명령/수동 확인만 적기. 없으면 "미실행"이라고 명시

## 출력 형식
마크다운만 출력. 앞뒤 설명 문장 없이 PR 본문만.
